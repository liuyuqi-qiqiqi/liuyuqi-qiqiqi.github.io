具身大模型理论｜第2章 大语言模型基础

发表于2026-07-20|更新于2026-07-21|具身大模型理论

本文为具身智能微专业配套核心课程《具身大模型理论》第二章「大语言模型基础」的学习笔记，授课教师为航天学院控制科学与工程系高亚斌老师。本章承接绪论中关于语言模型基本概念的讨论，从工程实现与架构设计的视角，系统深入地展开 Transformer 结构原理、生成式预训练语言模型 GPT、大语言模型结构演进以及注意力机制优化方法四大核心知识板块，为后续深入理解具身智能中大语言模型的部署与优化奠定扎实的架构基础。

一、语言模型的基本定位

语言模型的根本目标是建模自然语言的概率分布，这是自然语言处理研究中最基础的核心任务之一。从方法论演进的角度，语言模型可分为三个主要阶段：

  • n 元语言模型（n-gram Language Models）：基于马尔可夫假设，通过统计 n-gram 频率来估计条件概率，辅以平滑技术缓解数据稀疏问题；
  • 神经语言模型（Neural Language Models）：利用前馈神经网络、循环神经网络等深度学习模型对 进行估计，引入词向量实现分布式表示；
  • 预训练语言模型（Pre-trained Language Models）：基于 Transformer 架构，通过海量无标注文本进行自监督预训练，再针对下游任务进行微调。

自 2020 年 OpenAI 发布 GPT-3 以来，对大语言模型的研究逐渐深入。尽管大语言模型的参数量巨大，通过有监督微调和强化学习能够完成极为多样的任务，但其基础理论的核心仍然离不开对自然语言的概率建模。这正是本章展开讨论的逻辑起点。

二、Transformer 结构

Transformer 结构由 Google 在 2017 年提出，并首先成功应用于机器翻译任务。其核心创新在于：完全通过注意力机制完成对源语言序列和目标语言序列全局依赖的建模，摒弃了传统基于循环结构的序列建模方式。如今，几乎所有大语言模型均基于 Transformer 结构构建。

本节以应用于机器翻译的**编码器-解码器（Encoder-Decoder）**架构为例，系统介绍 Transformer 的核心组件。

2.1 注意力机制的基本原理

注意力机制（Attention Mechanism）是深度学习中的一项关键技术，其设计灵感来源于人类视觉和认知过程中的注意力分配方式——正如我们在阅读时会不自觉地将注意力集中在关键词上，注意力机制使神经网络能够动态地关注输入数据中最相关的部分。

注意力机制通过三个核心组件协同工作：

  • Query（查询）：表示当前需要”关注”的目标，例如解码器当前待生成的词表示；
  • Key（键）：用于与 Query 进行匹配，反映输入元素的特征；
  • Value（值）：携带实际的信息内容，最终输出基于这些值的加权求和。

其核心思想可以概括为：动态地为输入数据的不同部分分配不同权重，从而使模型聚焦于与当前任务最相关的信息，抑制无关信息的干扰。

2.2 编码器-解码器总体架构

基于 Transformer 的编码器和解码器结构由若干基本 Transformer 块（Block） 堆叠而成，整体呈对称分布：

  • 左侧编码器（Encoder）：负责将源语言序列编码为上下文相关的表示；
  • 右侧解码器（Decoder）：以自回归方式逐词生成目标语言序列。

每个 Transformer 块接收一个向量序列 作为输入，并输出一个等长的向量序列 。其中 是当前 Transformer 块对输入 整合其上下文语义后对应的输出。这里的 和 分别对应文本序列中一个词元（Token） 的向量表示。

每个 Transformer 块内部由以下核心子层构成：

  • 注意力层：使用多头自注意力（Multi-Head Attention）机制整合上下文语义，使序列中任意两个单词之间的依赖关系可以直接建模，不依赖传统的循环结构，从而更好地解决长程依赖问题；
  • 位置感知前馈层（Position-wise FFN）：通过全连接层对输入序列中每个位置的表示进行更复杂的非线性变换；
  • 残差连接（Add）：一条直连通路分别作用于上述两个子层，将输入与输出直接相加，使信息在深层网络中流动更加高效，有利于模型优化；
  • 层归一化（Norm）：作用于两个子层的输出表示序列，对表示序列进行归一化操作，起到稳定优化过程的作用。

2.7 编码器与解码器结构

基于上述模块构建的编码器端较为直接：源语言文本序列依次经过每个 Transformer 块，对其上下文语义进行层层抽象，最终输出每个单词的上下文相关表示。

解码器端则更为复杂，与编码器端存在两个关键差异：

（1）掩码多头注意力（Masked Multi-Head Attention）

解码器在生成目标语言序列时采用自回归（Autoregressive）的方式——对于每个单词的生成过程，仅有当前单词之前的目标语言序列是可以被观测的。因此，解码器的每个 Transformer 块的第一个自注意力子层额外引入了注意力掩码（Attention Mask），用于掩盖当前时刻之后的文本信息，防止模型在训练阶段”偷看”后续单词，确保自回归生成逻辑在训练与推理时保持一致。

（2）多头交叉注意力（Multi-Head Cross-Attention）

解码器端在掩码自注意力层与前馈层之间额外插入了一个多头交叉注意力模块。该模块中：

  • Query 通过解码器前一层的输出进行投影；
  • Key 和 Value 使用编码器的最终输出进行投影。

交叉注意力的核心作用在于：在生成每一个目标语言单词时，使解码器能够”参考”编码器端输出的源语言上下文表示，从而确保翻译结果的语义忠实度与内容完整性。

综上，整个机器翻译的前向流程为：待翻译的源语言文本经编码器端每个 Transformer 块对其上下文语义层层抽象后，输出每个单词的上下文相关表示；解码器端以自回归方式，在每个时间步 根据编码器输出的源语言表示以及前 个时刻已生成的目标语言文本，生成当前时刻的目标语言单词。

3.3 预训练语言模型实践

HuggingFace 是当前最主流的开源自然语言处理软件库，其核心贡献之一是 Transformers 库——基于该库，研究人员可以快速加载预训练模型、进行下游任务微调，以及实现新的网络结构。此外，HuggingFace 提供的 Datasets 库能便捷下载自然语言处理研究中常用的基准数据集。

以构建 BERT 模型为例，典型的预训练实践流程如下：

  1. 数据集准备：通过 Datasets 库直接加载大规模预训练语料（如英文维基百科数据集）；
  2. 训练词元分析器（Tokenizer）：BERT 采用 WordPiece 分词算法，根据训练语料中的词频动态决定是否将一个完整单词切分为多个子词单元；使用 transformers 库中的 BertWordPieceTokenizer 类完成词元分析器的训练；
  3. 预处理语料集合：基于训练好的 Tokenizer 将预训练语料转换为模型可接受的输入格式，对超过最大长度（如 512 个词元）的文档进行截断处理；
  4. 模型训练：在预处理好的语料上，配置模型超参数并启动训练流程；
  5. 模型使用：训练完成后，可针对不同应用需求（如句子补全、文本分类等）加载并使用模型。

四、大语言模型的结构

当前，绝大多数大语言模型均采用了类似 GPT 的架构——即基于 Transformer 架构构建的仅由解码器组成的网络结构，采用自回归方式构建语言模型。然而，在位置编码、层归一化位置、激活函数等实现细节上，不同模型各有探索与改进。

  • GPT-3：文献详细介绍了其模型架构、训练数据组成、训练过程及评估方法，但由于未开放源代码，根据论文直接复现整个训练过程并不容易；
  • OPT（Open Pre-trained Transformer Language Models）：根据 GPT-3 的描述进行复现并开源；
  • LLaMA：Meta AI 仿照 GPT-3 架构开源，公开评测结果及微调后的下游模型均表现优异。

值得注意的是，自 GPT-3 之后，OpenAI 不再开源模型，因此 ChatGPT 和 GPT-4 的具体架构细节尚不完全可知。

基于上述组件构建解码器层，采用自回归方式利用训练语料进行模型训练的过程与 GPT 基本一致。LLaMA 提供了 7B、13B、33B、65B 等不同参数规模的版本，各版本的超参数（如层数 、隐藏维度 、注意力头数 等）按规模递增进行调整。

4.2 注意力机制优化

在 Transformer 结构中，自注意力机制的时间和存储复杂度与序列长度呈平方关系，这占据了大量的计算设备内存并消耗了巨大的计算资源。如何优化自注意力机制的时空复杂度、增强计算效率是大语言模型面临的核心挑战之一。对此，学界主要从两条路径展开研究：

  • 近似注意力：从算法层面减少注意力计算和内存需求，包括稀疏近似、低秩近似等方法；
  • 硬件感知优化：从计算加速设备的硬件特性出发，研究如何更好地利用 GPU 等硬件对注意力层进行高效计算。

（1）稀疏注意力机制

对训练好的 Transformer 模型进行注意力矩阵分析发现，其中大量注意力权重是接近零的稀疏分布。因此，可以通过限制 Query-Key 匹配对的数量来降低计算复杂度，这类方法统称为**稀疏注意力（Sparse Attention）**机制。

稀疏化方法可进一步分为基于位置和基于内容信息的两类。

基于位置的稀疏注意力主要包含五种基本模式：

  • 全局注意力（Global Attention）：为部分特定位置保留全局感受野；
  • 带状注意力（Band Attention）：每个位置仅关注其邻近固定窗口内的位置；
  • 膨胀注意力（Dilated Attention）：按固定间隔跳跃式地选择关注位置，以扩大感受野；
  • 随机注意力（Random Attention）：随机选择若干位置进行关注；
  • 局部块注意力（Block Local Attention）：将序列划分为若干块，块内做全注意力计算。

现有的稀疏注意力模型通常是上述五种基本模式的复合组合，通过精心设计稀疏模式，在计算效率和模型效果之间取得平衡。

基于内容的稀疏注意力则根据输入数据本身的特性动态创建稀疏模式。一种简单而有效的方法是选择和给定 Query 有最高相似度的 Key 进行交互。代表性方法包括：

  • Routing Transformer：采用 K-means 聚类方法，对 Query 和 Key 进行聚类，每个 Query 只与其处在同一簇（Cluster）内的 Key 进行交互，中心向量采用滑动平均方法更新；
  • Reformer：采用**局部敏感哈希（Local-Sensitive Hashing, LSH）**方法为每个 Query 选择 Key-Value 对。其核心思想是使用 LSH 函数对 Query 和 Key 进行哈希计算，将它们划分到多个桶内，仅在同一个桶内进行注意力交互。设桶的个数为 ，给定一个大小为 的随机矩阵 ，LSH 函数定义为：

（2）FlashAttention

GPU 中的内存（显存）按物理位置和访问速度可分为多个层级：

  • 全局内存（Global Memory）和本地内存（Local Memory）：使用 HBM（High Bandwidth Memory），位于板卡 RAM 芯片上，容量大（如 H100 中为 80 GB），但所有线程同时访问时平均带宽有限；
  • 共享内存（Shared Memory, SRAM）和寄存器内存（Register Memory）：位于 GPU 芯片内部，容量极小（如 H100 每个 SM 的共享内存仅 228 KB），但访问速度远高于全局内存。

FlashAttention 正是通过利用 GPU 的硬件特性，针对全局内存和共享内存 I/O 速度的显著差异进行优化。其核心思想是：尽可能避免从 HBM 中读取或写入完整的注意力矩阵。具体策略包括：

  • 使用**分块（Tiling）**策略将注意力计算分解为多个小块，在 SRAM 中完成局部 Softmax 计算；
  • 通过存储前向传播的 Softmax 归一化因子（而非完整中间矩阵），在反向传播中快速重计算片上注意力；
  • 虽然重计算导致了额外的 FLOP，但由于大幅减少了全局内存访问量，整体运行速度更快且显存消耗更少。

（3）多查询注意力

**多查询注意力（Multi-Query Attention, MQA）**是多头注意力的一种重要变体。其核心特点在于：不同的注意力头之间共享同一组 Key 和 Value 参数，每个头仅单独保留独立的 Query 参数。这一设计使 Key 和 Value 的矩阵量降为单份，大幅减少了显存占用，显著提升了推理效率。

由于 MQA 改变了注意力机制的结构，模型通常需要从预训练阶段就原生支持。相关研究表明，也可以通过微调的方式为已训练好的模型添加 MQA 支持，仅需约 5% 的原始训练数据量即可达到良好效果。包括 Falcon、SantaCoder、StarCoder 在内的多个主流模型均采用了多查询注意力机制。

五、实践思考

预训练语言模型除了本章重点介绍的自回归模型 GPT 之外，还包括自编码模型 BERT、编码器-解码器模型 BART，以及融合上述三种方法的自回归填空模型 **GLM（General Language Model）**等不同范式。

ChatGPT 的出现使得目前几乎所有大语言模型的神经网络结构趋于趋同——均采用自回归解码器架构，基础框架与 GPT-2 一致，但在归一化函数、激活函数及位置编码等细节层面各具特色。归一化函数和激活函数的选择对大语言模型的收敛性具有显著影响——LLaMA 模型提出后，大多数开源模型沿用了 RMSNorm 和 SwiGLU 的组合方式，已成为事实上的架构标配。

在位置编码方面，由于 LLaMA 采用的 RoPE 方法的外推能力不足，后续研究探索了 ALiBi 等方法，通过线性偏置注意力使模型具备更好的上下文长度外推能力，从而支撑更长序列的建模需求。

大语言模型训练需要消耗大量计算资源，其中计算设备的内存是影响计算效率最重要的因素之一。注意力机制改进算法持续是模型架构层的研究热点，在 FlashAttention 的基础上，FlashAttention-2 等方法进一步优化了 GPU 线程调度和计算模式。如何更有效地利用计算设备内存，以及如何使内存消耗与模型上下文长度近似线性扩展，都是当前重要的前沿研究方向。

关于 GPT-4 的架构，有未经证实的消息称其采用了**专家混合模型（Mixture of Experts, MoE）**架构，总计约 1.8 万亿参数。据传 GPT-4 使用 16 个专家，每个专家的参数约为 1110 亿，每次前向传播通过门控路由激活其中 2 个专家，同时还有约 550 亿共享参数用于注意力机制。MoE 架构在显著减少单次推理所需有效参数量的同时，使模型总参数规模得以大幅扩展，代表了未来大语言模型架构发展的重要方向。

本章总结

本章作为《具身大模型理论》课程的第二讲，从工程架构的视角完成了以下核心知识点的系统梳理：

  1. Transformer 结构：从注意力机制的基本原理出发，系统拆解了嵌入表示层（含位置编码）、自注意力与多头注意力层、前馈层、残差连接与层归一化，以及编码器-解码器完整架构的设计逻辑与技术细节；
  2. 生成式预训练语言模型 GPT：阐述了无监督预训练的目标函数与训练范式、有监督下游任务微调的方法及灾难性遗忘的缓解策略，并介绍了基于 HuggingFace 的预训练语言模型实践流程；
  3. 大语言模型的结构演进：以 LLaMA 为典型代表，深入分析了 RMSNorm 归一化、SwiGLU 激活函数、RoPE 旋转位置嵌入等现代大语言模型的关键结构改进；
  4. 注意力机制优化：分别从算法的稀疏注意力机制（基于位置与基于内容两类）和硬件感知的 FlashAttention 两个维度，系统介绍了降低注意力计算复杂度的主流方法，并讨论了多查询注意力对推理效率的提升。
