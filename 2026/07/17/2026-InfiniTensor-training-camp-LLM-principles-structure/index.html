2026年夏季InfiniTensor训练营｜大模型原理与结构

发表于2026-07-17|更新于2026-07-17|2026夏季InfiniTensor训练营

本文为 2026 年夏季 InfiniTensor 训练营推理引擎方向第二课《大模型原理与结构》的学习笔记。上一节课《AI 模型导论与推理基础原理》已完成人工智能底层基础概念的梳理，搭建了从感知器、深度神经网络到训练原理的 AI 基础认知框架。从本节课开始，正式进入大模型推理系统的核心领域：作为系列课程的第二讲，本节将深入拆解大模型的基石——Transformer 架构。

一、为什么需要 Transformer

1.1 传统神经网络的局限

  1. Vector to Vector：输入输出维度固定，不便于直接处理变长序列（如手写数字识别这类固定维度任务）；
  2. 独立计算缺陷：矩阵乘法中各输入向量相互独立，无法感知”道可道”中不同位置”道”字的语义差异。

1.2 Sequence to Sequence 任务特性

  1. 变长映射：输入和输出均可为变长序列，且二者长度不必相等（如翻译、文本生成、语音识别）；
  2. 上下文依赖：词义随位置变化，需要捕捉全局信息。

1.3 早期解决方案及其瓶颈

  1. 滑动窗口：仅能捕获局部固定范围的上下文；
  2. 循环神经网络（RNN）：
    • 优点：理论上支持无限长上下文（依靠记忆模块 H 逐步传递）；
    • 缺点：存在梯度消失与信息衰减问题；串行计算导致硬件算力利用率低，无法并行。

二、自注意力机制（Self-Attention）

2.1 核心思想

  • 上下文 = 当前输入与其他所有输入的相关性分布；
  • 突破窗口限制，实现全局信息交互。

2.2 Q-K-V 计算流程

  • 线性映射：通过神经网络计算得到 Query、Key、Value 矩阵；
  • 注意力分数：由 Query 与 Key 计算得到各输入之间的相关性度量；
  • 大模型算子 Softmax：将注意力分数转换为概率分布（和为 1）；
  • Safe Softmax：减去最大值防止指数爆炸，保证数值稳定性；
  • 因果掩码（Causal Mask）：主要用于自回归注意力，屏蔽未来 Token，防止训练时”作弊”；
  • 矩阵并行化：将逐对向量运算转化为矩阵乘法，充分利用 GPU 算力。

2.3 旋转位置编码（RoPE）

  • 解决痛点：不包含位置信息的自注意力具有排列等变性，本身无法区分 Token 的先后顺序，因此需要显式引入位置信息；
  • 原理：通过绝对位置的三角函数（sin/cos）对 Q、K 向量进行几何旋转；
  • 优势：相对位置信息自然融入点积运算；角度表可预计算，推理高效。

三、自注意力层：多头注意力

  • 动机：将隐藏表示划分为多个注意力头，使模型能够在不同表示子空间中并行学习不同类型的语义关系和位置关系；
  • 机制：多组独立的 Q、K、V 并行计算，捕获不同子空间的语义相关性。

四、解码器（Decoder）模块

Decoder 模块的标准组件如下：

  • RMSNorm：基于均方根的归一化方法，通过对隐藏状态进行尺度归一化，改善深层网络训练和推理过程中的数值稳定性；
  • Residual：残差连接，缓解梯度消失，保留原始信息；
  • 多层感知器（MLP）：对注意力层输出进行非线性变换的前馈计算组件。

五、如何构建词表

  1. 分词算法：BPE（字节对编码）、WordPiece、Unigram，核心在于平衡词表大小与语义完整性；
  2. Tokenizer：完成文本与 Token ID 序列之间的相互转换；
  3. 文本嵌入（Embedding）层：
    • 输入嵌入：Token ID → 稠密语义向量（索引查找）；
    • 输出嵌入：隐藏状态 → 词表 Logits（矩阵乘法）。

六、大模型整体模型结构

综合以上组件，大模型的整体结构即为各模块的有序组装：输入文本经 Tokenizer 分词得到 Token ID 序列，经输入嵌入层映射为稠密语义向量；随后依次通过多层堆叠的 Decoder 模块（RMSNorm、多头自注意力、残差连接与 MLP）完成全局上下文信息的逐层交互与特征变换；最终由输出嵌入层将隐藏状态映射为词表 Logits，完成下一个 Token 的预测输出。

七、本课总结

本节课以”为什么需要 Transformer”为切入点，指出了传统神经网络在变长序列与上下文依赖处理上的局限，以及滑动窗口、RNN 等早期方案的瓶颈；进而系统梳理了 Transformer 架构的核心组件：自注意力机制的 Q-K-V 计算流程与 Safe Softmax、因果掩码等关键设计，RoPE 旋转位置编码的原理与优势，多头注意力的子空间并行学习机制，以及由 RMSNorm、残差连接、MLP 构成的 Decoder 模块；最后结合分词算法、Tokenizer 与 Embedding 层，完整拼接出大模型的整体结构链路。

至此，大模型的理论结构基础已经建立。后续课程将在此架构之上，进一步展开大模型推理流程与推理引擎的关键技术学习，逐步深入推理系统的工程实践，敬请期待。
